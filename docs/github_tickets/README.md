## Convention

- Un bloc `# ID - titre` correspond a une issue GitHub.
- Les dependances peuvent pointer vers des tickets d'autres depots.
- Les references `MGO-xxx` renvoient aux user stories du product backlog.
- Les estimations convertissent les story points en ordre de grandeur de jours : 3 SP ~= 1d, 5 SP ~= 2d, 8 SP ~= 3d, 13 SP ~= 5d.
